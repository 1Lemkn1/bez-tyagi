# 🫁 Без Тяги — трекер тяги к сигаретам

Живая версия: https://1lemkn1.github.io/bez-tyagi/

Мобильное веб‑приложение (PWA) для осознанного отказа от курения. Работает **полностью локально**: все записи хранятся в памяти телефона, сервер и интернет не нужны.

## Что внутри

Таблица триггеров, как в дневнике отказа:

| Поле | Описание |
| --- | --- |
| Дата и время | Подставляются автоматически, можно исправить |
| Место | Где была тяга |
| Что было прямо перед тягой | Контекст: кофе, ссора, звонок |
| Чувство за 10–30 секунд до тяги | Тревога, скука, злость, усталость |
| Сила тяги (1–10) | Слайдер |
| Что сделал(а) вместо | Альтернативное действие |

Плюс дополнительные возможности:

- ⏱ **Таймер тяги** — показывает, что тяга проходит за 2–3 минуты.
- ✅ **Метка «Закурил / Не закурил»** — из неё считается счётчик побед.
- 📊 **Аналитика** — график за 7 дней, топ‑3 мест, чувств и работающих приёмов.
- 📅 **Дней без сигареты** — с даты последнего срыва.
- 💾 **Экспорт / импорт JSON** — резервная копия записей.
- 📄 **Автономная версия одним файлом** — `public/app.html`.

## Деплой на GitHub Pages

Приложение статическое (все данные в `localStorage`), поэтому собирается в статику: `output: "export"` в `next.config.ts`, результат — в `out/`.

1. Репозиторий уже настроен: `.github/workflows/deploy.yml` собирает и публикует `out/` при push в `main`.
2. В настройках репозитория включите **Settings → Pages → Source: GitHub Actions**.
3. Адрес: `https://<логин>.github.io/bez-tyagi/`.

Сайт живёт в подпапке, поэтому сборка идёт с `NEXT_PUBLIC_BASE_PATH=/bez-tyagi` (задано в workflow). Локально переменная не нужна — приложение работает от корня.

Серверные API-роуты из шаблона (`/api/cravings`, `/api/health`) не используются клиентом и несовместимы со статическим экспортом: они перенесены в `src/server/api/` вне App Router и в сборку не попадают.

### Альтернатива: Vercel

1. Загрузите репозиторий в GitHub.
2. На https://vercel.com → **Add New… → Project** → выберите репозиторий → **Import**.
3. Переменные окружения не требуются.
4. **Deploy** → откройте выданный домен. Для Vercel `NEXT_PUBLIC_BASE_PATH` не задавайте.

## Установка на телефон (Android)

1. Откройте домен приложения в **Chrome** (не в инкогнито).
2. Подождите полную загрузку — service worker сохранит приложение в память телефона.
3. Меню **⋮ → «Установить приложение»** (или вкладка **Данные → 📲 Установить на главный экран**).
4. Если Chrome предлагает только «Создать ярлык» — используйте его: приложение также будет открываться на весь экран и работать офлайн.

После установки интернет не нужен: оболочка берётся из кеша, записи пишутся в localStorage.

## Структура

```
src/app/page.tsx           — главный экран
src/app/CravingTracker.tsx — интерфейс трекера (форма, аналитика, история, данные)
src/lib/localStore.ts      — локальное хранилище (localStorage) и резервные копии
src/lib/stats.ts           — расчёт статистики
public/manifest.json       — PWA-манифест
public/sw.js               — service worker (офлайн-кеш)
public/app.html            — автономная версия одним файлом
public/icons/              — иконки приложения 192/512 + maskable
```
